# 🌿 API - Espaço de Apoio para Ansiedade (Back-end)

API RESTful desenvolvida para a matéria de **Projeto de Software (AC 1)** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

Responsável pela persistência e gerenciamento seguro dos **check-ins de sentimentos** realizados no site.

🔗 **Front-end no GitHub:** [AjudaParaAnsiedadeSite](https://github.com/Milene-Arla/AjudaParaAnsiedadeSite/tree/master)  
🌐 **Site no Ar:** [Acesse na Vercel](https://ajuda-para-ansiedade-site.vercel.app/)

---

## 🚀 Funcionalidade (AC 1)

- **`POST /api/checkins`**: Cadastra um check-in emocional anônimo com nível de ansiedade (1 a 10), emoção e desabafo.

---

## 🛠️ Tecnologias

- **Kotlin** & **Spring Boot 3**
- **Spring Data JPA** (Hibernate)
- **Microsoft SQL Server** (Tabela `tb_checkin`)
- **Jakarta Validation**
